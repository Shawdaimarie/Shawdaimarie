## Activate in VS Code or Cursor

Clone https://github.com/Shawdaimarie/Shawdaimarie.git or pull its latest main
branch in an existing clean working copy. Open that repository folder in the
editor. Review the workspace settings and extension recommendations. Install
only extensions relevant to the current project. Recommendations do not install
extensions or language runtimes automatically.

For VS Code Copilot sessions, check that repository custom instructions are
enabled and that .github/copilot-instructions.md appears in the response
references. In Cursor, check that the engineering-standard rule is shown as an
active project rule. Ask the assistant to summarize the standard and language
evidence status as an activation check. This is a manual check; it has not been
run on the user's desktop.

## Activate in Replit

Open the intended Replit project. Import the GitHub repository if creating a
workspace for these profile materials, or merge replit.md and
docs/engineering-standard.md into an existing project. Preserve its architecture,
run commands, and prior instructions. Ask Agent to read replit.md and summarize
the shared standard and language evidence status. This profile repository has
no application entry point and does not need a deployment.

For a public bio, use:
"Software Engineer | AI Engineering & Technical Writing"
and link https://github.com/Shawdaimarie and

## Apply to other code repositories

Merge the editor files with each repository's existing settings and instructions.
